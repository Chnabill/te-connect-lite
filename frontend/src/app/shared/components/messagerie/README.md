# MessagerieComponent

This component allows employees to chat with HR in real time. It displays a list of HRs, lets the user select one, and shows a chat window for real-time messaging using REST and WebSocket APIs.

- Shows all HRs (users with role 'HR')
- Loads conversation history
- Sends messages
- Receives real-time updates
- Marks messages as seen

Usage: Add to routes and sidebar for employees.
